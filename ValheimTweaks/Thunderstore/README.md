# Valheim Tweaks

Small quality-of-life tweaks for Valheim. Every setting can be changed in game with
[Configuration Manager](https://thunderstore.io/c/valheim/p/shudnal/ConfigurationManager/) (F1),
and changes apply immediately.

## Features

### Mining drop multiplier

| Setting | Default | Range | Description |
|---|---|---|---|
| Mining / Iron drop multiplier | 1 | 0–10 | Multiplies scrap iron from muddy scrap piles and Mistlands ancient swords/armor. |

- Fractional results round up or down at random, so 1.5x averages 50% more.
- Stacks with the world's Resources modifier.
- Chests and creature drops are not affected.

## Multiplayer

Drops are rolled by the player who owns the mined object, which is usually whoever is nearest.
Settings are not synced yet, so every player should install the mod with the same values.
